# Shayona Multispeciality Hospital & ICU - Website

A complete, professional, and modern static website for Shayona Multispeciality Hospital & ICU located in Palanpur, Gujarat, India.

## 🏥 Project Overview

This is a fully responsive, static website built with HTML5, CSS3, and JavaScript. The website features a modern medical-grade design with a clean, professional layout suitable for a real hospital.

## ✨ Features

- **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional medical design with smooth animations
- **Complete Sections**:
  - Header with sticky navigation
  - Hero section with call-to-action buttons
  - About hospital with vision & mission
  - Departments/Specialities showcase
  - Expert doctors profiles
  - Facilities & infrastructure
  - Online appointment booking form
  - Gallery with lightbox effect
  - Patient testimonials
  - Contact information with Google Maps
  - Comprehensive footer

- **Interactive Features**:
  - Smooth scrolling navigation
  - Mobile hamburger menu
  - Scroll animations
  - Gallery lightbox
  - Form validation
  - Back to top button
  - Active navigation highlighting

## 🎨 Design Elements

- **Color Palette**: Medical blue (#0066cc), Medical green (#00a86b), White, and Gray tones
- **Typography**: Poppins (headings) and Roboto (body text) from Google Fonts
- **Icons**: Font Awesome 6.4.0
- **Animations**: Smooth fade-in, hover effects, and scroll animations

## 📝 Customization Guide

### Changing Colors:
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-blue: #0066cc;
    --secondary-blue: #004d99;
    --medical-green: #00a86b;
    /* ... */
}
```

### Adding/Removing Sections:
- Add new sections in `index.html`
- Style them in `style.css`
- Add scroll animations in `script.js` if needed

### Updating Content:
- Edit text directly in `index.html`
- Update contact information in the contact section
- Modify doctor profiles, departments, etc.
